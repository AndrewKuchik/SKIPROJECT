# Ski Game


Pamatuzdevumi

Projektā ir realizēti visi 7 Moodle norādītie uzdevumi ko mēs veidojām stundās


Papildus realizētais

Papildus pamatuzdevumiem tika pievienota līderu saraksta vizualizācija spēles beigu ekrānā. Pēc finiša spēlētājs redz labākos rezultātus, kas tiek saglabāti starp spēles reizēm.

Bonusa papildinājumi

Projektā tika pievienoti arī vairāki skaņas un vizuālie efekti:

Skaņu:
- skaņa finišā Crowd cheering;
- atšķirīgas skaņas pareizi un nepareizi izbrauktiem karodziņiem;
- crowd reakcijas skaņas pareizam un nepareizam karodziņam;
- skaņa sadursmei ar šķērsli;
- slēpošanas skaņa spēlētāja kustības laikā;
- slēpošanas skaņa apstājas, kad spēlētājs ir gaisā;

Vizuālie:
- sarkans "+3 sec" teksts, kad spēlētājs saņem soda laiku;
- slēpju pēdu efekts aiz spēlētāja;
- slēpju pēdu efekts pazūd, kad spēlētājs lec vai atrodas gaisā;
- sniegavīra sadursmes particle efekts;
